# Blacksmith Prototype

대장장이 성장 시뮬레이션 RPG의 프로토타입이에요. 목표는 "무기를 만들어 팔고, 능력이 자라고, 마왕군을 버티거나 진다"를 30일 동안 해보고 재밌는지 확인하는 거예요.

## 구조

| 폴더 | 내용 |
| --- | --- |
| `Core/` | 게임 규칙 전부. 엔진과 무관한 순수 C#이라 Unity로 옮겨도 그대로 쓴다. |
| `Core.Tests/` | Core 테스트 (xUnit) |
| `godot/` | Godot 4 프로젝트. 화면과 입력만 맡는다. |
| `godot/data/` | 재료와 품목 정의 (JSON). 코드 수정 없이 품목을 늘릴 수 있다. |

밸런스 숫자(하루 행동 수, 퇴보 비율, 침공 주기 등)는 `Core/GameRules.cs` 한 곳에 모여 있어요.

## 실행

1. [Godot 4.7 .NET 버전](https://godotengine.org/download)과 .NET 8 SDK를 설치해요.
2. Godot에서 `godot/project.godot`을 열고 실행(F5)해요.

테스트: 저장소 루트에서 `dotnet test`

## 지금 되는 것

- 하루 4행동 턴제, 하루 마치기
- 채집(무학 성장), 구매(화술 성장, 화술이 높으면 할인), 제작(품목별 능력치 성장), 판매(화술 성장), 왕국군 납품(명성 +)
- 능력치 3쌍: 한쪽 +1이면 반대쪽 -0.6
- 7일마다 마왕군 침공. 납품한 방어력 / (방어력 + 위협) 확률로 방어. 결과는 시드로 고정돼서 세이브-로드로 바꿀 수 없음
- 30일 버티면 승리, 침공을 못 막으면 게임오버
- 행동할 때마다 자동 저장 (`user://save.json`)

## 아직 임시인 것

- 제작 품질은 미니게임 대신 임시 난수(힘이 높을수록 평균이 오름)
- 화면은 버튼만 있는 임시 UI

## 안드로이드로 내보낼 때

내보내기 설정의 "리소스 외 파일 필터"에 `*.json`을 넣어야 `data/` 파일이 포함돼요.
