# 로그라이크 블랙스미스 기획서

Oct 15, 2026 · @가람

## 개요

대장장이로 시작해, 무엇을 만들고 어떻게 파느냐에 따라 능력치와 진로가 갈라지는 판타지 중세 성장 시뮬레이션 RPG예요.

- **장르**: 생활·경영 시뮬레이션 RPG. 상시 저장이지만 게임오버가 장기적 결과라 되돌리기 어려운 세미 로그라이트예요.
- **배경**: 고증에 얽매이지 않는 판타지 중세
- **핵심 재미**: 내가 자주 한 일이 내 미래가 되는 감각. 무기를 만들면 용병단장이, 돈에 집중하면 상인이 되는 식
- **트레이드오프**: 한쪽에 집중하면 반대되거나 관련 적은 능력은 퇴보해서 모든 길을 다 갈 수는 없음
- **공간 확장**: 작은 대장간에서 시작해, 확장한 공간에 어떤 역할을 주느냐가 진로를 바꿈
- **긴장감**: 마왕군이 게임오버 조건이자 최종 목표

표시된 "제안"은 Claude가 채운 가안이고, 나머지는 가람 님 구상이에요.

## 핵심 루프

원재료를 얻어 만들고, 팔거나 공급해 성장하고, 그 성장으로 더 좋은 제작에 도전하는 순환이에요.

&#91;embedded content: 핵심 루프 · 4단계 순환\]

마왕군 침공이 무기 수요를 만들고, 성장이 조건에 닿으면 다음 역할로 전직해요. 전직 방식과 조건은 제안이에요.

**시간은 턴제**예요. 하루에 행동을 3\~5개만 주어서, 무엇에 행동을 쓰느냐가 곧 어떤 능력을 키울지의 기회비용이 돼요.

**원재료는 세 가지 길**로 얻어요. 각각 다른 능력과 자원을 소모해요 (소모 내용은 제안).

| 방식 | 대가 | 함께 자라는 능력 |
| --- | --- | --- |
| 직접 채집 | 행동, 위험 | 힘, 무학 |
| 거래 | 돈 | 화술 |
| 의뢰 | 돈이나 물건 | 화술, 패기 |

## 제작 미니게임

제작은 미니게임으로 품질을 정해요. **제작 한 번에 미니게임 세 판**을 하는데, 판마다 아래 목록에서 무작위로 골라요. 같은 게 연속으로 나와도 돼요. 품질은 세 판 점수의 평균이에요.

품목마다 미니게임을 고정하면 그 미니게임을 못하는 사람은 그 품목을 영영 잘 만들 수 없어요. 품목과 상관없이 고르면 누구든 운이 좋으면 자기가 잘하는 것만 세 번 할 수도 있어요.

| 미니게임 | 하는 법 | 쉬워지는 능력치 |
| --- | --- | --- |
| 망치질 | 움직이는 흰 선이 초록 구간에 올 때 한 번 누르기 | 힘 (구간이 넓어짐) |
| 풀무질 | 3초 동안 연타. 첫 입력부터 시간을 잼 | 힘 (만점 20번 → 14번) |
| 세공 | 보이는 방향 6개를 순서대로 누르기 | 섬세함 (4초 → 6초) |
| 온도 유지 | 누르고 있으면 달궈지고 떼면 식음. 바늘을 초록 구간에 3초 동안 두기 | 섬세함 (바늘이 덜 출렁임) |
| 숫돌질 | 3초 동안 좌우 번갈아 누르기. 같은 쪽을 두 번 누르면 0.3초 멈춤 | 패기 (만점 18번 → 12번) |
| 담금질 | 누르고 있으면 게이지가 차고 초록 칸에서 떼기. 끝까지 차면 실패 | 무학 (칸이 넓어짐) |
| 각인 | 방향 5개가 잠깐 보였다 사라지면 같은 순서로 누르기 | 학문 (1.5초 → 3초 보여줌) |

**귀찮지 않게 하는 장치**

- 한 판은 몇 초면 끝나요.
- 같은 품목을 직접 3번 만들면 자동 제작이 열려요. 최고 품질의 80%로 미니게임 없이 만들어요.
- 판이 바뀔 때 0.4초 동안은 입력을 받지 않아서, 연타하던 손이 다음 판으로 새지 않아요.

**입력 환경**: 모든 미니게임과 UI는 PC 키보드·마우스, 스마트폰 터치, 게임패드 세 환경에서 모두 할 수 있어야 해요. 미니게임은 확인 버튼 하나, 좌우, 네 방향만 써서 세 환경에 똑같이 대응해요. 화면 버튼으로도 모두 할 수 있고, 안내 문구는 마지막으로 쓴 장치에 맞춰 바뀌어요. 보이는 걸 직접 찍는 방식(예: 과녁 클릭)은 터치가 너무 유리해서 넣지 않아요.

## 능력치 시스템

능력치는 레벨업으로 찍는 게 아니라, 자주 쓰는 스킬, 생산하는 품목, 자주 내리는 명령에 따라 자라요. 대신 한쪽이 자라면 반대되거나 관련 적은 능력은 퇴보해요.

능력치는 서로 반대되는 3쌍, 6개예요. 퇴보는 같은 쌍 안에서만 일어나고, 쌍마다 한쪽을 고르면 조합이 8가지라 그대로 성향 유형이 돼요. 이름은 가안이에요.

| 쌍 | 키우는 행동 (제안) |
| --- | --- |
| 힘 ↔ 섬세함 | 무기 제작 ↔ 장신구·정밀 도구 제작 |
| 화술 ↔ 패기 | 판매·흥정 ↔ 위협·거래 압박 |
| 무학 ↔ 학문 | 채집·호위 ↔ 설계·장부 |

**명성**은 6개 능력과 별도인 하나의 ± 수치예요. 훈련이 아니라 선택과 행적으로 변하고, +쪽은 명예, −쪽은 악명이에요. 예를 들어 상인과 밀매상, 직업군인과 용병단장을 가르는 기준이 돼요. 세력별 평판은 넣지 않아요.

주 능력치가 1 오르면 반대 능력치는 0.5\~0.7 떨어져요. 두 능력을 번갈아 키우면 행동 하나당 실제로 남는 건 0.3\~0.5라서, 올라운더는 가능하지만 한 우물만 판 때보다 행동이 2\~3배 들어요.

## 역할 확장

전직은 한 길로 올라가는 게 아니라, 상대적으로 높은 능력을 조건으로 다음 역할이 해금되는 갈래길이에요. 아래 역할은 가람 님이 든 예시예요.

&#91;embedded content: 역할 분기 · 집중한 활동에 따라 3갈래\]

모든 역할을 한 번에 맡을 수는 없고, 한쪽으로 갈수록 다른 갈래는 능력 퇴보로 멀어져요. 역할마다 새 시스템이 하나씩 더해져서, 갈래 수가 곱 구현량이에요.

갈래 전환도 얼마든지 가능해요. 상인 테크를 타다 장인 테크로 갈 수 있지만, 낭비한 시간과 돈만큼 마왕군은 계속 자라서 자칫하면 전멸해요.

전투는 직접 하지 않고 명령과 결과만 보여주는 방식(자동 전투)으로 해요. 주인공은 대장장이이고, 전투는 내가 만든 물건과 내린 명령의 결과를 보여주는 자리예요.

## 공간 확장

작은 대장간에서 시작해 공간을 늘리고, 늘린 공간에 어떤 시설을 짓느냐가 진로를 바꿔요. 능력치가 "내가 누구인가"라면 공간은 "내가 무엇을 가졌나"예요.

대장간은 핵심이자 메인이고 절대 바꿀 수 없는 공간이에요. 대장간에서 더 높은 등급의 생산을 파고들지는 개인의 선택이고, 확장 공간을 다른 역할에 쓰면 대장간의 중요도는 낮아질 수 있어요.

| 시설 | 얻는 것 | 이어지는 진로 |
| --- | --- | --- |
| 작업공간 + 숙소 | 후학 양성, 공장 수준 대량생산 | 군수사업자, 장인 |
| 매대 + 창고 | 더 많은 판매와 재고 | 상인, 밀매상 |
| 주점 | 용병 모집 | 용병단장 |
| 사교장 | 정치세력과의 연, 정책에 영향 | 정치인 |

진로 연결은 제안이에요. 공간이 한정되면 시설 선택자체가 트레이드오프가 돼서, 능력 퇴보와 같은 방향으로 집중을 유도해요.

## 마왕군과 게임오버

게임오버는 세 가지예요. 둘은 오랫동안 쌓인 결과이고 하나는 그 자리의 운이에요.

| 게임오버 | 원인 | 성격 |
| --- | --- | --- |
| 마왕군에 의한 멸망 | 마왕군의 성장과 침공을 막지 못함 | 장기 |
| 전투 중 전사 | 직접 전투에 참여 | 확률 (단기) |
| 정치적 암투로 암살 | 쌓인 적대 관계와 세력 다툼 | 장기 |

- **마왕군의 압박 (제안)**: 일정 주기마다 침공 웨이브가 오고 점점 강해져요. 왕국군에 무기를 대주면 방어력이 오르고 품질이 결과에 반영돼요.
- **최종 목표**: 마왕 토벌. 어떤 진로를 탔느냐에 따라 끝내는 방법이 달라질 수 있어요 (최고의 검을 바치기, 용병단을 이끌기, 정책으로 왕국을 묶기).

## 저장과 세미 로그라이트

언제든 저장할 수 있지만, 게임오버의 원인이 오래전에 시작돼서 직전 세이브를 불러와도 소용이 없는 구조예요. 아주 먼 과거로 돌아가지 않는 이상 결과를 되돌릴 수 없으니 사실상 세미 로그라이트가 돼요.

- **장기 결과**: 마왕군의 성장과 정치적 적대는 수십 턴에 걸쳐 쌓여서, 불러와도 이미 늦은 상황이 돼요.
- **단기 결과 (전사)**: 확률이라 로드로 피하기 쉬워요. 전투에 들어가는 순간 결과를 정해두면(난수 고정) 로드해도 같은 결과가 나와서, 참전할지 말지의 결정 자체가 무게를 갖게 돼요 (제안).
- **경고 신호 (제안)**: 장기 게임오버는 소문, 보고서, 협박 편지 같은 징조를 미리 보여줘야 불공정하게 느껴지지 않아요.

## 게임 흐름 (초안)

한 판은 타이틀에서 시작해 하루(아침, 행동, 저녁)를 반복하고, 침공에서 무너지거나 목표를 이루면 엔딩과 연대기로 끝나요.

&#91;embedded content: 게임 흐름 · 타이틀부터 엔딩까지\]

| 화면 | 하는 일 | 지금 프로토타입 |
| --- | --- | --- |
| 타이틀 | 새 게임, 이어하기 | 없음 (바로 게임 시작) |
| 새 게임 설정 | 난이도 선택 | 없음 |
| 인트로 | 마을, 대장간, 마왕군 소문 소개 | 없음 |
| 아침 | 오늘의 소식, 사건, 들어온 의뢰 | 없음 |
| 행동 | 채집, 구매, 제작, 판매, 납품 | 있음 |
| 저녁 | 오늘 번 돈, 능력 변화, 침공까지 남은 날 | 로그 한 줄만 |
| 침공 판정 | 방어 확률과 결과를 보여주는 장면 | 로그 한 줄만 |
| 엔딩과 연대기 | 어떻게 끝났고, 무엇을 만들고 어떤 길을 걸었는지 | "승리"·"게임오버" 글자만 |

30일을 버티면 저녁 뒤에 바로 엔딩으로 가요. 이어하기는 저장된 날의 아침부터 시작해요.

## 난이도

난이도는 한 판에 몇 갈래까지 해볼 수 있느냐로 나눠요.

| 난이도 | 마왕군 | 플레이 느낌 |
| --- | --- | --- |
| 평화 | 없음 | 게임오버 없이 성장과 경영만 |
| 쉬움 | 느리게 성장 | 이것저것 해볼 수 있음 |
| 보통 | 보통 | 한두 갈래에 집중해야 함 |
| 어려움 | 빠르게 성장 | 하나를 잘 깎고 운도 따라야 승리 |

난이도별로 마왕군 성장 속도만 바꾸고 퇴보 비율은 고정하면 밸런스 조절이 단순해져요 (제안). "평화" 이름은 가안이에요.

## 개발 조건

혼자, 마감 없이, C# 개발자가 만드는 프로젝트예요.

- **플랫폼**: PC 우선, 안드로이드 고려
- **현재 자산**: 없음 (구상만 있음)
- **엔진**: Godot 4 (C#), 맞지 않으면 Unity로 전환
- **아트**: 도트 기반 2D + 일러스트
- **참고**: 정해진 레퍼런스는 없고, 최근 플레이한 활협전의 영향을 조금 받았을 수 있음

입력은 PC 키보드·마우스, 스마트폰 터치, 게임패드 세 환경을 모두 고려해요. 미니게임이든 UI든 새로 만들 때마다 세 환경에서 다 할 수 있는지 확인해요.

혼자서도 만들 수 있는 구상이지만 전부 한 번에는 크고, 비용의 대부분은 역할 갈래 수, 아트 양, 경제 밸런스 세 곳에서 나와요. 그래서 세 단계로 나눠 만드는 걸 권해요.

## 엔진 선택

**Godot 4 (C#)로 시작하고, 맞지 않으면 Unity로 넘어가기로 했어요.** 옮길 가능성을 열어두려면 게임 로직을 엔진과 무관한 순수 C# 클래스로 두고, Godot에는 화면과 입력만 맡기는 게 좋아요.

|  | Unity | Godot 4 (C#) |
| --- | --- | --- |
| C# 지원 | 기본 언어 | 지원 (.NET), 기본은 GDScript |
| 안드로이드 | 안정적, 사례 많음 | C# 안드로이드 내보내기는 비교적 최근에 지원 |
